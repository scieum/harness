공통 패턴
- 화면 헤더에 "멤버 수 + 초대 버튼"을 한 줄로 둔다(이지태스크·코웨이).
- 역할은 이름 옆 작은 배지 또는 보조줄 텍스트("엄마 · 관리자")로 표시하고, 본인은 '나' 배지로 구분한다.
- 초대 대기는 활성 멤버와 섹션 또는 탭으로 분리하고, 인원 수·초대일·상태 텍스트를 함께 보여준다(신한·아이쿠카).
- 삭제·내보내기 같은 파괴적 동작은 행 우측 텍스트 버튼이나 화면 최하단으로 떼어 두고, 본인 행에는 노출하지 않는다.

Lab_Stock 적용 제안
- 화면 8: 헤더 "사용자 N명 + [초대] pill(검정)" → 섹션 "멤버"(행 = 이름 + 역할 배지 admin/member, 흑백 아웃라인) → 섹션 "초대 대기 (N)"(행 = 이메일 + 초대일 + '대기' 텍스트)로 구성한다.
- 역할 변경은 행 › → 바텀시트 라디오(admin/member)로 처리하고, 선택값만 하늘색(#2b9fe0 테두리 + #e6f4fc 배경)으로 표시한다. 핑크는 쓰지 않는다(재고 부족 전용).
- 삭제(내보내기)는 행 상세 맨 아래 텍스트 버튼 → 확인 모달(그림자 없이 1px 보더 + 딤)로 처리하고, 본인·마지막 admin 행에는 버튼을 숨긴다.

Lab_Stock 적용 제안
- 화면 7 입고: 시약 선택 → 수량 카드 [− | 입력 | +] + 단위 suffix(병/mL/g) → 보조 1줄(현재 재고 → 입고 후 재고) → 하단 '입고' pill(검정) 순으로 배치한다.

- 하한 0에서 −는 회색 비활성. 입력 후에도 재고가 기준 미만이면 그때만 핑크(#d6246a) "재고 부족" 텍스트를 띄운다. 입력 오류(음수·빈값)에는 핑크를 쓰지 않고 검정 보조 텍스트로 안내한다.

공통 패턴

- 권한 거부·인식 실패는 별도 화면으로 보내지 않고 프레임 자리나 입력 필드 아래에서 인라인으로 처리하며, 대안 수단을 함께 준다(마미톡·빽다방).
- 스캔 진입점은 상단 아이콘과 리스트 행 두 군데에 둔다(제페토).

Lab_Stock 적용 제안
- 스캔 화면: 흑백 딤 위에 흰 프레임, 상단 안내 "시약장 문에 붙은 QR을 맞춰주세요", 플래시 원형 버튼, 하단에 '시약장 번호로 찾기' pill(흰 배경 + 검정 보더)을 고정한다. 인식 성공 시 바로 해당 시약장의 시약 목록/MSDS 상세로 이동한다.
- 인식 실패나 다른 학교 QR(N1 학교별 분리 위반)은 프레임 아래 검정 텍스트 1줄 + '직접 찾기' 대안으로 안내한다. 핑크는 재고 부족 전용이라 오류 표시에 쓰지 않는다.
- 진입점은 홈 상단 QR 아이콘과 시약 검색창 옆 두 곳에 두고, 스캔 중 상태 강조(프레임 테두리 펄스 등)가 필요하면 하늘색(#2b9fe0)만 사용한다.
