- 떠 있는 카드·화면에 그림자를 쓴 사례가 대부분(Clarity·믹스패널·플리더스). 그림자 없이 가는 테두리 + 받침판 색 차이로 겹침을 보여 준 사례: dovetail 기능 카드, KRDS 카드, Clarity 받침판(받침판 자체는 그림자 없음).

## 관찰 요약

1. "어떤 서비스인지"를 첫 화면에서 가장 빨리 보여 주는 건 **실제 앱 화면**이다. 업무형 SaaS 중 Clarity·믹스패널은 헤드라인 옆/아래에 진짜 대시보드를 두고, 일부러 아래를 잘라 "스크롤하면 더 있다"를 만든다. 일러스트만 쓴 곳(플리더스·인프런)은 분위기는 있지만 무엇을 하는 도구인지는 글에 의존한다.
2. 헤드라인은 짧다: 2줄, 국문 약 50px 안팎, 핵심어 하나만 강조. 그 아래 부제 1~2줄 + 버튼 2개(주 = 가입/시작, 보조 = 데모/둘러보기)가 정석이고, Clarity는 버튼 위에 "특징 3개를 · 로 이은 한 줄"을 둬서 신뢰 요소를 첫 화면에 넣었다.
3. 제품 화면은 "본 화면 1장 + 핵심 기능 카드 1~2장 겹치기"가 공통 문법(Clarity·dovetail·유광기). 겹친 카드가 그 서비스의 차별점(Clarity = AI 요약, 유광기 = 숫자 카드)을 짚는다.
4. 아래 섹션 순서는 대체로 **신뢰(로고·숫자) → 기능 3~5개(글 + 화면 조각) → 단계/대상 → 후기 → 마지막 CTA 띠 → 푸터**. 기능 섹션은 "꼬리표 → 제목 → 점 목록 3 → 테두리 버튼" 틀을 반복해 리듬을 만든다.
5. 무채색 사례는 "색을 하나만, 누를 것과 핵심 숫자에만" 쓴다(뮤즈바이 주황, 위시켓·KRDS 탭 밑줄). Lab_Stock의 "핑크 = 결정 신호(badge-low-stock 안), 하늘색 = 선택·아이콘 강조" 규칙과 같은 방향이다.

### 스크롤 아래 섹션 순서안

1. **기능 탭 줄(고정)** — 위 접는 선 띠가 스크롤 시 상단 고정(Clarity).
2. **문제 공감 3카드** — 가운데 제목 "과학실 시약, 이렇게 관리하고 계신가요?" + 3열 인용 카드(따옴표 + 교사 말투 2줄: "엑셀 파일이 선생님마다 달라요" / "시약장 어디에 뒀는지 매번 찾아요" / "다 떨어진 걸 실험 당일에 알았어요") + 밑줄 한 줄 "Lab_Stock은 학교별 시약장 하나로 답해요."(뮤즈바이). 카드는 `canvas-soft` 면, 그림자 없음.
3. **기능 소개 4개(글 + 화면 조각, 좌우 번갈아)** — 탭 줄 항목과 1:1. 틀은 Clarity 고정: 꼬리표 → 제목 1줄 → 점 목록 3 → `button-outline` 또는 텍스트 링크. 화면 조각은 승인 화면에서 잘라 쓴다(유광기·플리더스처럼 카드 하단에서 잘림, 플리더스처럼 2장 계단식 겹침 가능).
   - 시약 목록 ← 2-desktop 표 + 필터 줄
   - 사용 기록 ← 13-desktop "최근 사용 기록" + 사용 기록 입력 드로어(`detail-drawer`) 조각
   - 재주문 알림 ← 재고 부족 행 + `badge-low-stock`(핑크는 배지 안에서만)
   - QR 찾기 / 시약장 ← 시약장 칸 배치 화면 조각("칸 16개 중 지정 14 · 미지정 2")
4. **이렇게 써요(단계)** — 뮤즈바이 스텝퍼: 번호 원 5개를 선으로 연결(1 학교 선택(NEIS) → 2 시약 등록 → 3 시약장 칸 지정 → 4 사용 기록 → 5 재주문 알림). 현재 단계 원은 하늘색 테두리/채움, 나머지 회색. 아래 큰 카드 하나: 왼쪽 "STEP n / 5" + 제목 + 설명 + 체크 목록 3, 오른쪽 그 단계의 실제 화면 조각.
5. **누가 쓰나요(대상 탭)** — KRDS 대상 탭: 교사 / 학생 / 관리자. 탭마다 왼쪽에 할 수 있는 일 카드 2개(테두리 카드), 오른쪽에 그 역할이 보는 화면 조각(학생 = 둘러보기·조회 위주, 관리자 = 시약장 설정). 역할별 노출은 기존 스펙의 역할 표를 그대로 따른다.
6. **안심하고 쓰는 이유(2×2 격자)** — 믹스패널식, 카드 없이 hairline으로만 칸 나눔: 학교별 데이터 분리(N1) · 인증 정보는 서버에서만 처리(N2, 키 이름·값은 쓰지 않음) · NEIS 공식 학교 정보로 가입 · MSDS·GHS 정보 연결. **실제 운영 숫자가 생기기 전까지 "○○개 학교 사용" 같은 숫자 카드는 넣지 않는다**(숫자 섹션은 운영 데이터가 생기면 이 자리에 추가).
7. **마지막 CTA 띠** — `canvas-soft` 띠, 가운데 제목 1줄 "우리 학교 시약장, 오늘 정리해 보세요" + `button-primary` 회원가입 + `button-outline` 둘러보기(Clarity·플리더스). 그림·그림자 없음.
8. **푸터** — 4열(Lab_Stock 워드마크 + 한 줄 소개 / 서비스: 시약 목록·사용 기록·QR 찾기 / 도움말: 이용 안내·자주 묻는 질문 / 문의) + 구분선 아래 저작권·개인정보처리방침·이용약관(플리더스·KRDS). 링크가 적으면 뮤즈바이식 단순 푸터(운영 주체 · 저작권 · 약관 링크 2개)로 줄인다.
