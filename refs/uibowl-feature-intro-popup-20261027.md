## 3. 공통 패턴

1. **보지 않기는 언제나 작은 회색 텍스트 버튼**이고, 주 버튼(써 보기·자세히)보다 약하다. 위치는 (a) 주 버튼 아래 가운데, (b) 카드 맨 아래 한 줄에 "보지 않기 | 닫기" 좌우, (c) 카드 바깥 위 — 세 가지. "보지 않기 + 닫기"를 둘 다 두는 곳은 (b)가 깔끔하다(LG ThinQ).
2. **그림이 위, 글이 가운데, 버튼이 아래.** 기능 소개는 실제 화면 조각이나 사용 장면 그림을 크게 넣는다(모두의주차장·사방넷).
3. **모바일은 바텀시트 또는 가운데 카드**, **데스크톱은 가운데 모달 + 위 오른쪽 ✕**. 데스크톱에서는 ✕가 있고, 모바일 가운데 카드는 ✕ 없이 텍스트 "닫기"를 쓰는 경우가 많다.
4. 주 버튼은 하나(기능으로 바로 가기). 두 번째 행동은 텍스트 버튼.
