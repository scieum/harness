# PRD: (가칭 미정) 과학실 시약 관리 SaaS

## 1. 한 줄 설명
고등학교 과학실 시약장의 시약 종류·재고량·입고일자·사용날짜·사용자를 확인하고,
QR코드로 MSDS를 연결하며, 재고가 부족해지면 판매처를 연결하는 SaaS.

## 2. 사용자
- 전국의 과학 교사와 학생
- 학교마다 admin이 있고, 같은 학교의 다른 교사·학생이 함께 사용한다.

## 3. 역할과 권한
| 역할 | 할 수 있는 일 |
|---|---|
| 학생 | 사용량 기록 |
| 교사 | 입고(수량 올리기), 시약 정보 입력, 사용량 기록 |
| admin | 교사 권한 전체 + 사용자 초대·삭제, 판매처 설정 |

## 4. 핵심 행동
- 수량을 올린다(입고).
- 자료를 입력한다(시약 정보, 실험 매뉴얼).
- 사용량을 저장한다.

## 5. 재주문 기준
- 사용자가 실험 매뉴얼을 올리고 조 수를 입력하면, 1반 1회 실험에 필요한 양을 자동으로 계산한다.
- 현재 재고가 이 양보다 적으면 판매처를 연결한다.
- 계산 방식: AI(저렴한 Gemini 모델)로 매뉴얼에서 시약별 사용량을 추출 → 조 수를 곱함.
  - API 키는 서버에서만 사용한다.
  - 추출 결과는 사용자가 확인한 뒤 저장한다.
- 매뉴얼이 없는 시약은 교사·admin이 시약 상세(화면 3)에서 재주문 기준을 숫자로 직접 입력한다. (2026-10-06 추가)
- 재주문 기준이 없는 시약은 자동 기준(최근 4주 평균 주간 사용량 × 2주, 사용 기록이 없으면 마지막 입고량의 20%)을 쓰고 "자동"으로 표시한다. 매뉴얼·직접 입력 값이 우선. (2026-10-07 추가)
- 품의서·영수증·거래명세서(PDF·사진)를 올리면 AI가 품목을 읽고, 사용자가 확인한 뒤 한 번에 입고한다. 같은 키를 서버에서만 사용한다. (2026-10-07 추가)
- MSDS 주소는 한국산업안전보건공단 MSDS Open API로 시약명·CAS를 검색해 채운다. 공공데이터포털 서비스 키는 서버에서만 사용한다. (2026-10-07 추가)
- 학교 목록은 나이스(NEIS) 교육정보 개방 포털 학교기본정보 API로 불러온다. NEIS 인증키도 서버에서만 사용한다.

## 6. 데이터 원칙
- 학교별로 데이터를 따로 관리한다. (다른 학교의 시약·재고·사용 기록과 섞이지 않는다.)

## 7. 화면 범위 (이번 시안)
1. 로그인: 개인 이메일 + 비밀번호 (학교는 가입 때 저장, 2026-10-02 변경)
2. 시약 목록(재고 부족 표시) — 2026-10-07: MSDS 없는 시약 일괄 찾기 띠(교사·admin) / 필터·정렬(보관 분류·보관 위치·MSDS 없는 시약·정렬, 모든 역할)
3. 시약 상세(MSDS QR 연결 포함) — 2026-10-06: 보관 위치 줄 + 위치 바꾸기(시약장 → 칸, 교사·admin), 재주문 기준 직접 입력(교사·admin) / 2026-10-07: MSDS 없는 시약에 MSDS 찾기(교사·admin), 자동 재주문 기준 "자동" 표시, 위치 피커에 추천 칸
4. 사용 기록 입력 — 2026-10-07: 사용일 고르기(기본 오늘, 미래 불가)
5. 실험 매뉴얼 업로드 → 추출 결과 확인
6. 재주문 알림 → 판매처 연결
7. 입고·시약 등록 (교사·admin) — 2026-10-02 추가 / 2026-10-07: 맨 위 '직접 입력 / 서류로 입고' 전환(기본 서류로 입고), 서류 업로드 → AI 품목 읽기 → 확인 표(시약 연결·새 시약 펼침·MSDS 찾기) → 한 번에 입고 → 새 시약 위치 추천
8. 사용자 관리: 초대·삭제 (admin) — 2026-10-02 추가
9. 판매처 설정 (admin) — 2026-10-02 추가
10. 사용 기록 내역 (모든 역할) — 2026-10-02 추가 / 2026-10-07: 사용일 기준으로 묶고 정렬, 기록한 날이 다르면 함께 표시
11. 시약장 설정: 문 형태(양문형·단문형)·단 수(3단·4단)·칸별 보관 분류 지정 (교사·admin, 학생은 보기만) — 2026-10-02 추가 / 2026-10-04: 학교당 시약장 여러 개 — 시약장 전환·추가·이름 바꾸기·삭제(삭제 시 그 시약장의 시약은 "칸 없음"), 시약장 0개 빈 화면 / 2026-10-06: 칸 누르기 → 칸의 시약 목록 + 시약 넣기·빼기(교사·admin), 시약장 고정 번호, QR 인쇄(교사·admin), 저장 안 한 편집 확인
12. QR 스캔 → 시약장·시약 상세 (모든 역할) — 2026-10-02 추가 / 2026-10-06: 결과 시트 = 그 시약장의 시약 목록 + 칸 위치 + 배치도 보기(→11), 직접 찾기 = 시약장 번호
13. 홈(대시보드): 재고 부족 요약·최근 사용 기록·바로가기(QR 스캔·사용 기록 등)·시약장 요약 (모든 역할, 역할별 노출 다름) — 2026-10-02 추가
14. 회원가입: 학교 선택(NEIS 시/도 → 지역(시/군/구) → 학교) + 이름·개인 이메일·비밀번호 — 2026-10-02 추가
15. 랜딩(로그인 전 첫 화면): 서비스 한 줄 소개 + 핵심 기능 3~4개(학교별 분리·NEIS 학교 선택·QR 스캔·재고 부족 알림) + 로그인·회원가입 버튼 — 2026-10-03 추가
- 둘러보기(비회원, 2026-10-03 추가): 랜딩(15)의 "둘러보기"로 들어가 데모 학교(읽기 전용) 데이터로 홈(13)·시약 목록(2)·시약 상세(3)를 본다. 쓰기 동작은 비활성, 상단 띠에서 가입 유도.
