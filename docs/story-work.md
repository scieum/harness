# 작업 흐름: Lab_Stock 화면 디자인 (AI 없이 손으로 했던 실제 순서)

> 이 문서는 "내가 실제로 어떻게 했는지"다. "무엇을 위한 일인지"는 story-service.md에 있으며, 둘을 섞지 않는다.

## 실제 순서

1. 나는 uibowl에서 경쟁사 레퍼런스를 수집한다.
2. 나는 레퍼런스를 분석해 우리 서비스에 반영할 부분을 가져온다. `[멈칫]`
3. 나는 분석 내용을 토대로 화면 설계 문서를 구체화한다.
4. 나는 Figma에 레퍼런스와 화면 설계서를 반영한 UI 키스크린 2~3개를 390×844로 그린다.
5. 나와 내부 관계자들이 협의해 컨셉 시안을 확정한다. `[멈칫]` `[넘김→내부 관계자]`
6. 나는 확정된 시안으로 디자인 토큰과 컴포넌트를 만들고 화면 디자인에 들어간다.
7. 나는 완성된 시안에서 토큰·컴포넌트가 우리 가이드를 위반한 부분이 없는지 검수한다. `[멈칫]`
